# 大学内 勉強スペース紹介ページ

大学内の、図書館等の勉強スペースについて情報をまとめたWebページ。
（2023年現在）

## 公開URL

https://weebee1212.com/fresh2024/studyspace/

## 概要

学内各キャンパスにおける図書館やラーニングコモンズの情報を集約したWebページ。
キャンパスごとにマップから直感的に場所を探し、詳細ページでそれぞれの特徴をわかりやすく把握することができる構成。

## 制作背景・担当範囲

大学内で所属していたサークルの「新入生企画」として、他部署（編集、PR、カメラ、デザイナー等）のメンバーを含む新入生複数人のグループで、約1年間をかけて制作。
企画構成や取材などは全メンバーで協力しつつ、自身は特に、Web部署の所属としてWebへの実装を担当。デザイナーが完成させたデータを画面に反映、ポップアップやスライドショー等の動きをつけ、レスポンシブへの対応も行った。

## 使用技術

- PHP
- HTML
- CSS
- JavaScript

## 実装のポイント

- **レスポンシブ対応**: スマートフォン専用表示にとどめず、PCやタブレット等の各画面幅に応じたレイアウトを実装。
- **マップUI**: キャンパスマップ上のピンへのクリック・ホバーに連動した、対象施設の情報のポップアップ表示を構築。
